# Team Brainstorm

## When to Use

Invoke when the user has an idea to explore — for a product, feature, business model, content strategy, or any creative direction — and wants structured exploration, challenge, and synthesis before committing to a direction. Produces an Idea Brief, which is the required input for the tech-brainstorm team if the idea routes to a technical build.

## What You Need Before Starting

- An idea, topic, or question from the user (any level of vagueness is fine — concept-explorer handles clarification)
- Brain team context loaded (philosophy.md, memory/index.md) — lead-brain co-chairs this session

## What This Team Produces

- Concept map: 9-dimension exploration of the idea
- 7-signal challenge report: all Proactive Signal Protocol signals addressed
- Exactly 2–3 synthesized option directions with routing recommendations
- Idea Brief: structured output for routing to BUSINESS RESEARCH / MARKETING / BRAIN UPDATE / TECH-BRAINSTORM
- Session synthesis: routed to data team for archiving

## Agent Sequence (mandatory order)

1. `concept-explorer` — maps the idea across 9 dimensions (no evaluation)
2. `idea-challenger` — fires all 7 Proactive Signal Protocol signals (session gate — must complete before synthesis-builder)
3. `synthesis-builder` — produces exactly 2–3 option directions after challenge

Lead-brain loads philosophy.md and surfaces memory/index.md prior sessions before concept-explorer begins.

## Key Rules

- idea-challenger MUST fire before synthesis-builder — this is a session gate, not optional
- synthesis-builder produces exactly 2–3 options — never 1, never 4+
- All 7 Proactive Signal Protocol signals must be addressed — even if the answer is "no concern found here"
- Corruption test must run ("if this succeeds and a power-hungry actor acquires it, what do they do?")
- trustworthy-sources skill required before citing any external market data in the challenge signals
- Session output is deposited by data team after session closes — never skipped
- BMAD is user-request-only — never invoked proactively

## How to Invoke

Tell lead-brainstorm the idea or question. Lead-brainstorm activates lead-brain as co-chair, then runs the three-agent sequence. The user decides which option direction to pursue at the end — the team presents, not decides.
