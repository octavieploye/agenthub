# Team Brain

## When to Use

Invoke when the user needs to understand the current state of the Optimaeus ecosystem (entities, architecture, project status, strategy), or when a brainstorm or tech-brainstorm session needs ecosystem context loaded before it begins. The brain team co-chairs brainstorm and tech-brainstorm sessions.

## What You Need Before Starting

No external inputs required — the brain team reads from architecture files, project docs, and memory. However, load a specific focus area when possible (e.g., "focus on hephaestus entity" or "focus on current sprint status").

## What This Team Produces

- Ecosystem orientation brief: entity roles, cascade positions, current build phase, active constraints
- Project status summary: all entities with their operational/in_sprint/planned/blocked status
- Strategic context: sovereignty-first framing, business model phase, roadmap sequencing
- Memory surface: relevant prior sessions from the memory folder, if applicable
- Brain alignment check for brainstorm sessions: does the proposed idea violate any core or sovereignty principle?

## Agent Sequence

1. `ecosystem-architect` — entity roles, tech stacks, cascade dependencies, API contracts
2. `project-navigator` — current project statuses, active sprints, TODO items
3. `strategy-advisor` — business model, roadmap sequencing, sovereignty-first framing
4. `memory-curator` — prior session findings relevant to the current topic (co-chairs brainstorm sessions)

Agents may be invoked selectively — not all 4 are required for every brain session.

## Key Rules

- All claims cite specific source files — no paraphrasing from memory
- Philosophy.md is loaded at session start for brainstorm co-chair sessions
- Sovereignty violations are always flagged — never silently included
- trustworthy-sources skill required before citing any external reference
- Brain team does NOT make strategy decisions — it provides context for the user to decide

## How to Invoke

Tell lead-brain the focus: ecosystem orientation, project status, strategic context, memory surface, or brainstorm co-chair. Lead selects the relevant agents for the focus area.
