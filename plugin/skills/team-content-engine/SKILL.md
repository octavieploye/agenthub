# Content Engine Team

General-purpose content marketing workflow. Takes any product, service, or tool as input and produces a full research-to-content pipeline.

## When to Use

- User wants to create a content strategy for a product, service, or tool
- User needs competitive research + audience study + persona development
- User wants multi-channel content (LinkedIn, YouTube, X, website)
- User wants buyer psychology analysis (Validator/Investigator/Skeptic)
- User wants to understand why people don't buy (objection/friction modeling)
- User wants paid ads strategy (Google Ads, Facebook Ads — conditional)

## What You Need Before Starting

- A product, service, or tool to create content for
- User confirmation of target channels (default: LinkedIn, YouTube, X, website)
- Optional: existing marketing materials, website URLs, competitor names

## What This Team Produces

### Research Phase (docs/content-research/[subject]/)
1. **Product Audit** — internal deep dive: value prop, features, pricing, unique mechanism
2. **Competitive Analysis** — competitor landscape, content audit, positioning gaps
3. **SEO/GEO Report** — keyword opportunities, competitor keyword gaps, AI search visibility
4. **Audience Study** — demographics, psychographics, channel behavior, pain language
5. **Personas** — 5 personas (power user to unaware) with V/I/S buyer psychology classification
6. **Objection Model** — frictions, fears, doubts mapped per persona and buyer type

### Strategy Phase (docs/content-research/[subject]/)
7. **Content Strategy** — brand methods, messaging framework, channel strategy, content calendar, content brief queue

### Creation Phase (docs/content-creation/[subject]/)
8. **LinkedIn posts** — ready-to-publish drafts
9. **X threads** — ready-to-publish threads
10. **Blog posts** — full drafts or structured briefs
11. **Website copy** — agent decides format
12. **YouTube scripts** — structured briefs with hooks and segments
13. **Podcast outlines** — topic flow and key talking points
14. **Paid ads** (conditional) — Google Ads, Facebook Ads, or directory/prospecting plans

## Agent Sequence

| Flock | Phase | Agents | Max Concurrent |
|---|---|---|---|
| 1 | P1: Product Deep Dive | product-analyst | 1 |
| 2 | P2+P3: Research | competitive-researcher + audience-researcher | 2 |
| 3 | P4+P5: Psychology | persona-builder + objection-modeler | 2 |
| 4 | P6: Strategy | content-strategist | 1 |
| 5 | P7: Creation | content-writer + video-scriptwriter | 2 |
| 6 | P8: Paid (conditional) | paid-channel-strategist | 1 |

## Frameworks Embedded

- **V/I/S Buyer Psychology** (Adam Erhart) — Validator, Investigator, Skeptic identification and pattern-specific content
- **5 Brand Methods** — Flip the Status, Hijack the Myth, Open the Hidden Door, Build the Ritual, Give a Superpower
- **6 Personal Brand Principles** — Fear of Being Seen, Superpower, Tribe Language, Trade School to Church, Purpose, Packaging
- **Facebook 4-Trigger** (conditional P8) — Avatar, Problems, Unique Mechanism, Offer
- **Google Ads SKAg** (conditional P8) — Single Keyword Ad Groups, match types, landing page alignment
- **Directory Foot-in-the-Door** (conditional P8) — Value-first prospecting, courtesy calls

## Key Rules

- Max 3 agents active at any time
- User gate after P6 (content strategy) before creation begins
- P8 is conditional — only if user requests paid/outreach channels
- Never invent buyer language — source from P3 audience study
- Never claim capabilities not in P1 product audit
- All research must apply trustworthy-sources evaluation
