# Conversion Architect Team

Orchestrates a 4-phase, 5-agent workflow that builds conversion architecture for Opeidos: landing page, checkout flow, and GEO/SEO hooks calibrated for the non-tech 40-50y business owner who resists AI.

## When to Use
- You want to understand why non-tech users leave Opeidos before buying
- The landing page hero, CTA, or checkout flow needs a strategic overhaul
- You need to map AI resistance (fear, skepticism, complexity) to a compelling "1% edge" positioning
- You want a 0.1% conversion blueprint ready to hand to the design/dev team
- Opeidos GEO and SEO need to be baked into the landing page architecture

## What You Need Before Starting
- Access to the Opeidos landing page (URL or page content/screenshot) — required by cia-page-reviewer in Phase 1
- The current CTA and hero headline — for the teardown comparison

## What This Team Produces

| Phase | Agent | Output |
|---|---|---|
| 1A (parallel) | bounce-analyst | Bounce Psychology Report — 15 top emotional triggers for exit, cart, and checkout abandonment |
| 1B (parallel) | cia-page-reviewer | CIA Page Teardown — kill zones, trust breakers, friction inventory, benchmark gap |
| 2 | ai-resistance-analyst | AI Resistance → Edge Positioning Map — fears, counters, vocabulary guide, positioning hook |
| 3 | conversion-blueprint | Conversion Architecture Brief — hero, social proof, CTA, checkout, GEO hooks, user journey, A/B tests |

Final deliverable: **Conversion Architecture Brief** — a complete, buildable specification for the landing page and checkout flow.

## Agent Sequence

1. **lead-conversion-architect** — loads core doctrine + benchmarks, spawns Phase 1
2. **bounce-analyst** + **cia-page-reviewer** (parallel, Phase 1) — simultaneous research and teardown
3. Lead reviews Phase 1 outputs — devil's advocate gate
4. **ai-resistance-analyst** (Phase 2) — receives Phase 1 context
5. Lead reviews Phase 2 output — positioning hook gate check
6. **conversion-blueprint** (Phase 3) — receives all three prior outputs
7. Lead reviews brief — presents to user for approval

## Key Rules
- Phase 1 runs 2 agents in parallel (bounce-analyst + cia-page-reviewer) — this is the only parallel phase
- Never more than 3 agents active simultaneously
- User approval required before the Conversion Architecture Brief is final
- GEO and SEO hooks are mandatory in the blueprint — Opeidos must be AI-search and Google-search optimized
- The team does NOT write copy — it produces structural specifications that the copywriter and dev team implement
- The team does NOT run A/B tests — it produces test hypotheses only
