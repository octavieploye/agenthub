# Clarity Copy Team

Produce CEO/manager-style Copy Packs (headlines, CTAs, taglines, bullets) for landing pages and campaigns. Four agents, one structured output.

**Not a research team.** This team assumes product and audience context already exists (project memory, landing-lab briefs, positioning docs). It focuses entirely on HOW the copy reads — applying the communication style of CEOs and managers: direct, specific, no jargon, one line = full picture.

## When to Use
- You need a full Copy Pack for a product or landing page
- Existing copy is generic, soft, or full of adjective soup
- You want a structured process: context intake → pain distillation → copy generation → critic gate → output
- You already have a brief from `landing-lab` or `conversion-architect` and want CEO-style execution

## What You Need Before Starting
- A product to write for (AgentHub, OPTimaeus, Opeidos, or any product)
- Target audience (1-3 segments)
- Optionally: existing copy to overhaul, a landing-lab brief, or positioning notes

## What This Team Produces

A **Copy Pack** per product/segment:
- 1 headline (max 8 words, problem-first)
- 1 subheadline (max 15 words, mechanism)
- 1 CTA (max 5 words, verb + specific outcome)
- 3 taglines (max 8 words each, different angles)
- 5 result-first bullets (max 12 words each)
- Critic score (1-10) + revision log

## Agent Sequence

1. **lead-clarity-copy** — reads project memory and docs, builds Context Brief, sequences all agents, assembles final Copy Pack. Does NOT write copy.
2. **pain-distiller** — takes Context Brief, compresses each audience segment's felt pain to exactly 1 sentence. No features. No adjectives. Pure pain.
3. **clarity-writer** — takes Brief + Pain Sheet, generates Draft Copy Pack using CEO communication principles. Produces 3 headline candidates per segment, selects the sharpest.
4. **copy-critic** — scores every line 1-10 on the CEO Clarity Scale, flags jargon and banned words, blocks approval if any line scores < 7, returns revision list to lead.

Revision loop: lead dispatches clarity-writer for rewrites if copy-critic blocks. Max 2 revision rounds. If still blocked after 2 rounds, escalate to user.

## Key Rules
- No agent uses banned words (powerful, seamless, revolutionary, innovative, leverage, utilize, enable, empower, synergy, robust, dynamic, transformative, disruptive, cutting-edge)
- copy-critic must block any line scoring < 7 — no exceptions, no partial approvals
- pain-distiller produces exactly 1 sentence per segment — never a paragraph
- lead assembles final Copy Pack only after copy-critic issues APPROVED verdict
- Final Copy Pack is presented to user for review before any commit or use
