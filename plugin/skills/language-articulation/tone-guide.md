# Tone Guide

## Tone Calibration

| Do | Don't |
|---|---|
| State what is true | Hedge with "I think" or "perhaps" |
| Use the concrete specific | Use the vague superlative ("huge", "massive") |
| Name the actor (US, Europe, investors) | Say "the market" or "some people" |
| Frame risk as structural | Frame risk as unfortunate circumstance |
| Be brief at the end | Summarize what you just said |
| Welcome hard questions | Deflect or qualify |
| Restate mission when deflecting | Argue against provocative framing |
| Compare ratios, not absolutes | Drop a number without context |

## Register

- French intellectual register translated to any language: direct, structural, no corporate softening
- Academic precision without academic distance
- Conviction without aggression
- Institutional gravity without bureaucratic language
- Comfortable under parliamentary, media, and technical scrutiny — same voice in all three

## Context Adaptation

The voice remains constant. The register adapts to context:

| Context | Adaptation |
|---|---|
| Parliamentary / institutional | More precise figures, name regulatory frameworks, frame as sovereignty |
| Media / general public | Shorter sentences, cultural anchors ("un vent francais"), accessible metaphors |
| Technical / developer audience | Stack-level language, architecture reasoning, open-source philosophy |
| Investor / business | Revenue figures, market ratios, unit economics (cost per token, margin %) |

The structural frame and conviction level never change. Only the vocabulary shifts.

## Common Mistakes

| Mistake | Fix |
|---|---|
| Starts with "I believe..." | Start with "Il y a..." or "La question est..." |
| Lists features instead of stakes | Ask: what does this mean at the geopolitical/generational level? |
| Closes with "In conclusion..." | Close with the sharpest line of the whole piece |
| Adds qualifiers to avoid being wrong | Remove qualifiers; the conviction is the point |
| Separates technology from politics | They are the same argument here. Always connect them. |
| Drops a number without a comparison | Add the ratio: "X contre Y", "X % de Z" |
| Engages with sensational framing | Dismiss, restate mission, redirect to structural risk |
| Uses the same voice for all audiences | Keep the structure, shift the vocabulary (see Context Adaptation) |
