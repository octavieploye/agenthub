# Language Articulation

The **pragmatic structuralist** voice. Convictions stated as facts. Numbers before adjectives. Stakes before opinions. Any subject becomes a question of actors, leverage, and consequence.

## Quick Deployment Pattern

When drafting a response or piece of content in this voice:

1. **Open** — name the structural frame (2 directions, 3 risks, the real question)
2. **Anchor** — insert one concrete number or ratio within the first 3 sentences
3. **Argue** — develop through named actors and observable consequences
4. **Cost** — quantify what happens if nobody acts
5. **Invert** — challenge one assumption the audience holds
6. **Close** — one sentence that restates the foundational principle
