# Graphic Identity Team

Takes any app, project, or business from zero identity to a complete, unforgettable graphic brand system. Every phase output is validated by a brand-conscience gate before the next phase begins. The workflow is LINEAR — no phase is skipped, no two specialists run simultaneously.

## When to Use

- An app, project, or business needs a visual identity built from scratch
- An existing identity needs full redesign starting from strategic foundation
- You need an identity system that targets premium buyers, not the mass market
- You need a brand system built on a defensible WHY, not aesthetic preference
- You need an identity that could build quasi-emotional loyalty (not just recognition)

## What You Need Before Starting

Nothing is required before starting — the intake phase collects everything. Bring only:
- The name of the subject (app, project, business, concept)
- Any rough initial information you have (sector, audience, constraints)

## What This Team Produces

| Phase | Output | Agent |
|---|---|---|
| 0 — Intake | Approved Project README + LOOP_MODE setting | lead-identity |
| 1 — Strategy | Brief analysis, SECTOR DEFAULTS, Golden Circle, buyer profile, adjacency map | identity-strategist |
| 2 — Research | Brainstorm (50-70), mind map, 20 verbal marks, 3 named axes | creative-director |
| 3 — Moodboards | 3 axis moodboard blocks (logos/type/color/materials), scored recommendation | moodboard-curator |
| 4 — Development | 3-5 logo concepts per axis, type+color systems, scored finalists, #1 recommendation | identity-builder |
| 5 — Presentation | Non-designer-readable presentation doc, FINAL LOGO CONFIRMED | identity-builder |
| 6 — System | Full identity system (7 logo variants, color, type scale, iconography, spatial rules, loyalty architecture) | brand-architect |
| 7 — Delivery | File structure, brand guidelines spec, mockups, quick reference card, readiness check | brand-architect |
| Synthesis | Master identity record + drift log | lead-identity |

## Agent Sequence

```
lead-identity (intake)
  → [brand-conscience check]
  → identity-strategist (Phase 1)
  → [brand-conscience check]
  → creative-director (Phase 2)
  → [brand-conscience check]
  → moodboard-curator (Phase 3)
  → [brand-conscience check]
  → identity-builder (Phase 4-5)
  → [brand-conscience check]
  → brand-architect (Phase 6-7)
  → [final brand-conscience check]
  → lead-identity (synthesis)
```

## Key Rules

- Never start creative work before Golden Circle (WHY/HOW/WHAT) is confirmed — this is Law 1
- Never use external references in Phase 2 — brain generates first, market references come in Phase 3
- Never present more than 3 logo concepts — internal curation is the specialist's job
- Never present without a committed #1 recommendation — no recommendation = concepts not good enough
- Apply Anti-AI Protocol (0.1% Rule) at Phases 2, 4 — reject the first 3 obvious forms every time
- Never activate next phase before brand-conscience check passes
- Never begin Phase 6 without FINAL LOGO CONFIRMED signal from user
