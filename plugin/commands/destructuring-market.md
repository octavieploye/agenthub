name: 'destructuring-market'
description: 'Destructure market entry strategy — segments, channels, positioning, go-to-market vectors. Input: subject brief + optional prior outputs. Output: MarketStrategyMap with segments, channels, positioning, entry vectors.'
---

IT IS CRITICAL THAT YOU FOLLOW THESE INSTRUCTIONS EXACTLY.

STEP 1 — Collect the SUBJECT BRIEF. Use any CompetitorMap or BusinessProfile from prior runs as context.

STEP 2 — Run the Segment Mapper agent:
Identify addressable segments beyond the obvious. Each segment: name, description, estimatedSize, painPoints, currentSolutions, underservedAspect.

STEP 3 — Run the Channel Strategist agent:
Map discovery channels per segment: channel, type (owned/earned/paid), segment, sequencing (pre-launch/launch/post-launch), rationale.

STEP 4 — Run the Positioning Analyst agent:
Map existing player positions, identify white space, design messaging architecture.

STEP 5 — Run the Entry Strategist agent:
Synthesize into ranked entry vectors: name, segment, channel, sequencing, rationale, riskLevel (low/medium/high).

STEP 6 — Produce the MARKET STRATEGY MAP.

Output format matches the MarketStrategyMap type from `@optimaeus/destructuring`.
