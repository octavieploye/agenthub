# Phase 4 — Synthesis + Standard Output
Roles: Synthesiser → Scribe
Receives: ANALYSIS-OUTPUT (Phase 2) + SHADOW-OUTPUT (Phase 3)
Final output: Standard intelligence report → Human

---

## SYNTHESISER: CONVERGENCE MAPPING

**Load-bearing convergence:**
What finding is confirmed by sources from at least three of the five traditions?
Mark each: `[CONVERGENT — N traditions agree]`
These can be trusted most — not because all traditions are right, but because the agreement persists across radically different starting assumptions.

**Productive divergence:**
Where do traditions produce genuinely different pictures?
Name the disagreement precisely. Name what is at stake — which decisions would come out differently depending on which picture is correct.
Do not resolve. Present both. Mark: `[DIVERGENT — tension between X and Y]`

**Shadow integration:**
Do not put the Shadow findings in a separate section. Integrate them. The corruption vector belongs in the same picture as the five-lens analysis. The abstraction of harm is a structural feature of the market, not a footnote.

**Unanswered questions:**
Name one or two questions the analysis has not yet asked itself. What territory remains unexplored. What a follow-up run should prioritize.

---

## SCRIBE: STANDARD OUTPUT FORMAT

Produce the final intelligence report in this exact structure. Do not add sections. Do not remove sections. Do not rename sections.

---

```markdown
# [Market Name] — Market Intelligence Report
*Sources: [N total] | Traditions: [A/B/C present] | Convergence: [threshold met / not met] | Date: [YYYY-MM-DD]*

## Market Question
[Exact restatement of what was asked]

## What the Models Reveal
[Multi-lens synthesis in prose. Not a table. What each tradition sees. What each misses.
The tension between traditions held in view, not resolved. Write as thought — not as a Confluence page.
Each tradition's contribution named, each tradition's blind spot named.]

## Convergence — What All Traditions Agree On
[Load-bearing findings. What persists across academic, institutional, heterodox, and complexity sources.
Each finding marked: [CONVERGENT — N traditions agree]
If below convergence threshold: note [BELOW CONVERGENCE THRESHOLD — N sources, findings unvalidated]]

## Productive Divergence — Where Traditions Disagree
[The substantive tension. Named precisely. What is at stake in the disagreement.
Both sides held, not adjudicated. Marked: [DIVERGENT — tension between X and Y]]

## What the Price Does Not Show
[Ecological costs. Power dynamics. Minsky position.
Externalized costs. Who pays what the market price does not carry.
Draws from Shadow Q6 and Lens 5. Specific — not gestured at.]

## The Corruption Vector
[From Shadow Q3. Specific. Not softened.
The structural feature enabling extraction — named, not categorized.]

## Data Required for Proper Modeling
[What a credible model of this market needs:
- Price/quantity time series and frequency
- Elasticities (own-price, cross-price, income) — and whether they are available
- SAM structure if CGE is needed
- Sectoral balance sheets if Minsky analysis is needed
- Behavioral parameters if ABM is needed
- Ecological accounts / true cost data if available
- Stylized facts the model must reproduce]

## How to Communicate These Results
[What format is honest about the uncertainty in this specific question?
Fan charts (probability distributions at each horizon) — if the question is about forecasting?
Scenario architecture with named assumptions — if the question is about policy?
Stylized fact tables — if the question is about financial market behavior?
Distributional output across income groups — if the question is about welfare?
Name the format. Name why it fits.]

## Sources
| Source | Tradition | URL |
|---|---|---|
| [title] | [academic / institutional / heterodox / complexity] | [URL] |

---
*Source count: [N] | Convergence: [met (≥5 non-corporate, ≥3 traditions agreeing) / not met] | Shadow: [integrated / missing — flag if missing]*
```

## GATE 4 CHECKLIST

```
GATE 4 CHECKLIST — FINAL OUTPUT
=================================
[ ] Shadow findings integrated — not in a sidebar, woven into the picture
[ ] At least one CONVERGENT finding marked [CONVERGENT — N traditions agree]
    OR [BELOW CONVERGENCE THRESHOLD] noted clearly
[ ] Productive divergence present (or noted as absent with reason)
[ ] Corruption Vector section present and specific
[ ] Data Required section populated with specific data needs
[ ] Sources table complete with verified URLs
[ ] NO summary verdict section
[ ] NO confidence percentages
[ ] NO triage table (CRITICAL / SIGNIFICANT / OPEN)
[ ] NO executive summary that replaces the synthesis
```

If any checklist item fails: return to the relevant phase — not to the human.

---

## WHAT THIS PHASE DOES NOT DO

- Does not produce a "summary verdict" that flattens the tension
- Does not add confidence that the sources did not earn
- Does not produce output that looks like a McKinsey deck or a Confluence page
- Does not deliver to human until Gate 4 passes
