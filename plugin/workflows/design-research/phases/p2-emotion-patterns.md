# Phase 2 — Emotional UX Patterns

**Agent:** emotion-ux
**Trigger:** Activated by lead-design-research after Trend Harvest Report is complete
**Input:** Trend Harvest Report + target context
**Output:** Emotional UX Pattern Map

## Objective

Map the emotional architecture of software landing pages: where trust is built, where delight is injected, where anxiety spikes, and how the user's emotional state is guided from first impression to conversion.

## Research Protocol

1. **Review Trend Harvest Report** — ground emotional analysis in observed visual patterns
2. **Map emotion to product category** — SaaS developer tools vs. consumer apps vs. B2B platforms have different emotional grammars
3. **Use NNG and Baymard as primary references** for UX psychology claims
4. **5-round search limit** — flag any gaps if patterns cannot be confirmed
5. **Produce Pattern Map** — fill all sections of the Emotional UX Pattern Map template

## Analytical Framework

### Emotional Arc Model

Map user journey across five emotional states:

```
Curiosity → Credibility → Desire → Hesitation → Commitment
```

For each state:
- What triggers it on the page
- What design elements sustain or accelerate it
- What design elements interrupt or reverse it

### Trust Signal Taxonomy

Rank trust signals by effectiveness for the product type:
1. Live usage numbers (active users, uptime %, deployments)
2. Named customer logos
3. Testimonials with photo + name + company
4. Press/media mentions
5. Security certifications / compliance badges
6. Open source indicators (GitHub stars, public repo)
7. Founder/team photos with names

### Delight Injection Points

Where positive emotional peaks should be placed:
- On page load (animation, welcome, personality)
- On hover (playful micro-interaction)
- On form focus (encouraging micro-copy)
- On submission success (celebration state)
- On empty states (humor or warmth)

### Friction Audit Focus

Highest-friction points in software landing pages:
- Unclear value proposition (cognitive friction)
- Ambiguous pricing (anxiety)
- Long signup forms (effort friction)
- No free trial / demo signal above fold (hesitation)
- Technical jargon without translation (exclusion)

## Output Format

Produce the Emotional UX Pattern Map. Deliver to lead-design-research upon completion.
