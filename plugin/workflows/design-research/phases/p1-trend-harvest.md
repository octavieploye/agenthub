# Phase 1 — Trend Harvest

**Agent:** competitor-trend-researcher
**Trigger:** Activated by lead-design-research with confirmed target context
**Output:** Trend Harvest Report

## Objective

Map current landing page and software UI trends relevant to the target product. Produce a structured Trend Harvest Report covering layout, typography, color, visual hierarchy, UI conventions, and design system patterns.

## Research Protocol

1. **Clarify scope** — confirm target product type (SaaS, developer tool, B2B, consumer) with lead
2. **Gather sources** — use WebSearch to find recent examples from Awwwards, Mobbin, Screenlane, and similar
3. **5-round limit** — if 5 WebSearch rounds do not yield sufficient pattern coverage, report what was found and flag the gaps
4. **Convergence check** — only report a pattern as a "trend" if 3+ sources confirm it
5. **Produce report** — fill all sections of the Trend Harvest Report template

## What to Look For

### Above-the-Fold Patterns
- Hero layout types: centered, split, full-bleed image, video background, illustrated
- CTA placement: center vs. inline vs. sticky
- Navigation: transparent overlay vs. solid bar vs. floating pill
- Headline patterns: claim + quantified benefit vs. verb-led imperative vs. question

### Section Flow Patterns
- Order of proof sections: social proof placement (above vs. below hero)
- Feature presentation: icon grid vs. screenshot carousel vs. interactive demo
- Pricing section structure: toggle (monthly/annual), highlight card, feature comparison

### Typography
- Variable font usage
- Weight contrast: heavy headline + light body vs. uniform medium
- Line height and spacing trends
- Monospace for technical products

### Color
- Dark mode default vs. light mode vs. dark/light toggle
- Gradient direction and usage (background vs. text gradient)
- Muted system palette vs. bold accent
- Glassmorphism: status and usage patterns

### UI Conventions
- Card designs: shadow style, border radius, hover lift
- Button styles: rounded vs. sharp, ghost vs. solid
- Feature grid density
- Testimonial card patterns

## Output Format

Use the Trend Harvest Report template from the animation-engineer command. Deliver to lead-design-research upon completion.
