# MODULE: f1.5-lateral
LAYER:  F1.5 — Adjacent Market Scan
MODE:   FORWARD
TOKENS: ~400

## LOAD FIRST
core/non-assumption-rule
core/csl-protocol
+ active geo/ modules
+ f1-eagle output (Macro Signal Map)

## SKIP IF
Project is defensive (protecting existing position, not scanning for new entry)
OR user explicitly deactivates this module at task creation.
If skipped: note "f1.5-lateral not run" in f2-sector input.

## INPUT
Required: Macro Signal Map from f1-eagle
Required: Primary sector hypothesis (from f1-eagle or user statement)
Optional: Known adjacent categories the user is aware of

## PROCESS
1. Identify up to 3 adjacent categories using these two criteria:
   a. Same customer base as the target sector, but different product
   b. Same distribution channel as the target sector, but different customer

2. Identify up to 2 technologies currently deployed in other sectors
   that could migrate into this one within 3 years

3. Check these sources for adjacent-origin players:
   - Y Combinator recent batches (cluster by problem domain, not sector label)
   - ProductHunt recent launches in adjacent categories
   - ArXiv applied papers in non-obvious domains
   - GitHub trending repos with cross-domain applicability

4. For each adjacent threat found, record:
   Origin / Migration vector / Timeline (label as projection) / Risk level

5. CSL item if: an adjacent threat appears to overlap with a known
   incumbent's stated roadmap (ambiguous — could be convergence or competition)

## OUTPUT: Adjacent Threat Map
Format per threat (max 5):
  Threat [ID]:
    Origin:           [adjacent category or company name]
    Migration vector: [how it could enter this sector]
    Timeline:         [estimated — explicitly labeled as projection]
    Risk:             Low / Medium / High
    CS:               [score]

Then:
  Explicit note if zero credible threats found (state reasoning — not assumption)
  CSL items: [list if any]

## HANDOFF
Forward feeds: f2-sector
Gate before handoff:
  - At least 1 threat identified OR zero-threat finding with explicit reasoning
  - All CSL items reviewed by user
