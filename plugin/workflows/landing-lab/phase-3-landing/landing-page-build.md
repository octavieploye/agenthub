# Phase 3: Landing Page Build
# Agent: landing-copywriter | Input: Phase 0 + Phase 1 + Phase 2 | Output: Landing Page Copy Document

## Purpose

Produce full landing page copy from the approved Value Proposition Document and Pain Mapping Report. No positioning decisions are made here — landing-copywriter expresses what has been approved.

---

## Hero Section Build (4-second window)

### Kicker
Show traction or a specific signal. Examples:
- "[N] [segment] already use [product]"
- "4.9 stars from [N]+ reviews"
- "[Specific outcome] in [specific timeframe]"

NOT: "The all-in-one platform for X" — this is a descriptor, not traction.

### Headline (produce 3 options)
- Uses simple words — zero jargon
- States problem and solution together
- Traceable to the one-sentence brand pitch from Phase 2
- Mark one as recommended with justification

### Subheadline
One sentence: HOW the product works. Mechanism, not feature list. Do not repeat the headline.

### Validation Row
2–3 specific credibility signals from Phase 0 credibility section:
- Specific numbers ("Used in 47 countries")
- External logos (only if documented in Phase 0)
- Award or press mention (only if documented in Phase 0)
NOT generic trust badges.

### CTA Button
Connects directly to headline message. Write the specific outcome the visitor gets.
- "See My Score" / "Find My Gap" / "Start Free — 3 Minutes" / "Get My Plan"
NOT: "Sign Up" / "Get Started" / "Learn More"

### Key Visual Brief
Written AFTER headline is finalized. Describe what the visual must communicate:
- Must show the connection between the stated problem and the solution
- NOT a generic product screenshot or stock photo
Format: `[VISUAL NEEDED: show [specific situation] transitioning to [specific outcome]]`

---

## Doubt-Clearing Section Build (2-minute window)

Work from the dependencies list in Phase 2. Order sections by buyer concern likelihood (most common objection first).

For each section:
1. Section headline (outcome-focused, not label)
2. Body copy (1–3 sentences max)
3. CTA repetition (same main CTA repeated)

### Mandatory Doubt-Clearing Sections

**Social Proof Block**
2–3 testimonial copy directions:
Format: "[Buyer type matching top segment] who [achieved specific outcome] in [timeframe]"
Provide: exact quote direction or placeholder `[TESTIMONIAL: direction for what this buyer describes]`
NOT: "great product" / "highly recommend" — too vague to convert.

**Use Case Map**
2–3 buyer category descriptions:
Format: "[Who they are] uses [product] to [specific outcome they get]"
Source segments from Phase 1 segment table.

**Credibility Block**
- One specific founder or team credential (role + achievement)
- One stat or research reference that supports the core claim (sourced from Phase 0 or Phase 2)
NOT a bio — one sentence of credibility + one sentence of proof.

### Conditional Sections (include only if Phase 0 documented the underlying asset)

- External validation: logos or press (only if in Phase 0)
- Video testimonial brief: `[VIDEO NEEDED: [buyer archetype] describing [specific before/after]]`
- FAQ: 3–5 questions from dependencies list + "Ask a question" link

---

## Pricing Section (include if product has pricing tiers)

Three-plan anchor:

**Plan A (Entry):** Lowest friction — minimal commitment, gets buyer in
**Plan B (Target):** Recommended — mark "Most Popular" or "Best Value" with visual emphasis
**Plan C (Anchor):** High price — must be ≥3× Plan B cost to function as anchor

Write plan name, one-line benefit description, and price placeholder for each.

---

## Assessment / Quiz Hook (include if product uses quiz or scoring entry point)

Choose ONE hook type (never blend):

**Frustration hook:**
> "Despite [common effort], you're still [specific pain from Phase 1 verbatim phrases]?"

**Results hook:**
> "Are you ready to [specific desired outcome from Phase 1 Before/After]?"

Subheadline:
> "Answer 15 questions to discover [your score / your gap / your readiness plan]"

Value promise — name the 3 areas to be measured (from product features):
> "We'll measure and improve your [Area 1], [Area 2], and [Area 3]."

CTA: "Take the Free 3-Minute Assessment — Get Instant Recommendations"

Dynamic results directions (write 3 copy variants):
- High-quality lead path → 1:1 meeting offer
- Mid-tier lead path → group event / webinar offer
- Low-engagement lead path → free content direction (podcast / guide / article)

---

## Final CTA Section

NOT a repeat of the top headline. Buyer has been educated by the full page. Write:
- Reference 2–3 of the most compelling proof points shown on the page
- Benefit-rich summary (use Phase 2 VP benefits)
- End with specificity: what happens immediately after clicking
- Social links placement note: "Follow us on [platform] — [N]K followers" (as credibility, not decoration)

---

## Flags Required in Output

- `[VISUAL NEEDED: description]` — every element requiring visual production
- `[NEEDS VERIFICATION: claim]` — any claim not fully confirmed in Phase 0
- `[TESTIMONIAL: direction]` — placeholder for social proof requiring real buyer input
- `[VIDEO NEEDED: description]` — video placement placeholders
