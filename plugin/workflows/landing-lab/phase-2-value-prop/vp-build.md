# Phase 2: Value Proposition Build
# Agent: value-prop-architect | Input: Phase 0 + Phase 1 | Output: Value Proposition Document

## Purpose

Build the structured value proposition that all downstream copy must express. This is the single source of truth for Phases 3 and 4. No copy agent makes positioning decisions — they express this document.

---

## Step 1: Define the VP Statement

Fill in the template using only sourced inputs from Phase 0 and Phase 1:

```
For [WHO — named segment from pain-mapper]
that is dissatisfied with [WHAT STATUS QUO — documented workaround]
due to [UNMET NEED — root cause from Four U's analysis],
[PRODUCT NAME] provides [SOLUTION — mechanism from product-researcher]
that delivers [KEY BENEFITS — specific, measurable, not "better/faster/cheaper"]
compelling enough that [SEGMENT] will take action.
```

Rules:
- WHO: the top segment from pain-mapper — never "businesses" or "users"
- KEY BENEFITS must be specific: numbers, outcomes, timeframes
- Never invent benefits not supported by product materials

---

## Step 2: Evaluate — Four U's Confirmation

Inherit the Four U's assessment from Phase 1 and confirm:
- Which U's score Strong?
- Does the value prop statement align with the strongest U?
- If fewer than 2 U's score Strong: **BLOCK** — flag to lead-landing-lab before continuing

Apply the Before/After lens:
- Confirm the product classification: Penicillin / Morphine / Vitamin (inherit from Phase 1)
- **Vitamin classification = flag to user** — copy alone cannot make a vitamin a must-buy; repositioning or segment change may be needed

---

## Step 3: 3D Breakthrough Test

Evaluate the solution's competitive differentiation:

| D | Test question | Result: Pass / Fail / Partial |
|---|---|---|
| Disruptive | New business model or delivery method vs. incumbents? | |
| Discontinuous | Does it let buyers do something they literally COULD NOT do before? | |
| Defensible | Moat: IP / switching cost / network effects / proprietary data? | |

At least 1 D must Pass. If 0 pass: **flag to lead-landing-lab** — copy cannot substitute for undifferentiated positioning. Present options to user: reposition / pick a narrower segment where differentiation exists / change the product offer.

---

## Step 4: MVS Confirmation

Confirm the Minimum Viable Segment:
- Name the MVS in one sentence: "[Role/demographic] who [context] and [specific pain]"
- Confirm this segment is reachable through a known channel
- Confirm the product delivers value to this segment without significant modification
- If multiple segments are in play: rank by pain intensity, name the P0 segment, note others for Phase 2 expansion

---

## Step 5: Dependencies Map

What external factors must be in place for the product to deliver its promise to this segment?

List all dependencies. These become the "what if" objections that landing-copywriter must address in doubt-clearing sections.

Examples:
- "Requires buyer to have an existing email list"
- "Assumes buyer has budget for X subscription per month"
- "Only delivers value if buyer uses the product at least [frequency]"
- "Requires integration with [tool] to function as described"

Each dependency = one doubt-clearing section in Phase 3.

---

## Step 6: One-Sentence Brand Pitch

```
We are the only [category] that [unique mechanism or approach] for [named segment].
```

This sentence must be:
- True and verifiable from product materials
- Specific — not "the best" or "the most powerful"
- Directly traceable in the hero headline produced in Phase 3

---

## Output: Value Proposition Document

1. VP statement (complete, filled in)
2. Four U's confirmation table (inherited + confirmed)
3. 3D breakthrough assessment table (Pass / Fail / Partial per D)
4. MVS statement (one sentence)
5. Dependencies list (ordered by buyer concern likelihood — feeds Phase 3 doubt-clearing order)
6. One-sentence brand pitch
7. Any flags requiring user decision before Phase 3 begins

This document is locked after user review. landing-copywriter and content-builder reference it as the sole source of positioning truth.
