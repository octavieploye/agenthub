# MANIFEST — Landing Lab Methodology
Version: 1.0
Modes: FORWARD (research → copy → review) | REVERSE (audit existing copy → flag → rebuild)

## LOAD ORDER
1. Load ALL core/ modules first (always in context)
2. lead-landing-lab loads phase-0-discovery/product-intake.md at session start
3. Load one phase module at a time — unload previous before loading next
4. Load synthesis/final-package.md when all phases complete
5. Load ops/ modules only when explicitly needed

## BEFORE STARTING — MANDATORY
Present user with intake questions (see phase-0-discovery/product-intake.md).
If product materials are insufficient: create Data Request List and pause until user provides inputs.
USER CONFIRMATION GATE after Phase 0 — do not begin Phase 1 without explicit user approval of Product Discovery Brief.

## CORE (always load)
core/conversion-principles.md     Foundational conversion frameworks: 4-second hero, doubt-clearing, 3-plan pricing, assessment funnel benchmarks
core/value-prop-framework.md      Define-Evaluate-Build: Four U's, Before/After, Gain/Pain ratio, 3D breakthrough test, MVS

## FORWARD MODULES (Research → Copy → Review)
Entry: user has a product to build landing presence for

  phase-0-discovery/product-intake.md    P0   Product brief, philosophy, features, market, credibility — user-confirmed
  phase-1-pain/pain-mapping.md           P1   Four U's per segment, Before/After, Gain/Pain ratio, verbatim phrases
  phase-2-value-prop/vp-build.md         P2   VP statement, 3D test, MVS, dependencies, brand pitch
  phase-3-landing/landing-page-build.md  P3   Hero + doubt-clearing + pricing + assessment hook + final CTA
  phase-4-content/content-production.md  P4   3 pain-oriented articles + onboarding copy + founder note
  phase-5-conversion/conversion-review.md P5  Section-by-section audit, top 3 flags, readiness score

## REVERSE MODULE (Audit Existing Copy)
Entry: user has existing copy to audit before rebuild

  phase-5-conversion/conversion-review.md   R0  Run conversion-reviewer first on existing copy
  → flag structural issues → determine which FORWARD phases need to be (re)run

## SYNTHESIS
  synthesis/final-package.md    Complete Landing Lab output package — all 6 documents structured for handoff

## OPERATIONS
  ops/how-to-run               HOW/WHEN/WHY/WHAT — read by lead-landing-lab at session start
  ops/data-request-list         Missing data protocol — pause and request from user before proceeding

## TOKEN BUDGET GUIDE
core/ total:             ~600 tokens   (always in context)
one phase module:        ~500 tokens   (load/unload as you go)
synthesis/:              ~400 tokens   (load at end only)
Maximum in context:      ~2,500 tokens (fits any window)

## HANDOFF
Output routes to:
- team-marketing: if campaign strategy and channel planning needed after copy is complete
- team-geo-optimizer: if AI search visibility and GEO optimization needed for the landing page
- graphic-identity-team: if brand visual system is needed to support the landing page
