# Stage 2 — Tight Brief

**Agent:** lead-ux-challenge
**Active agents:** 1

## Purpose
Compress Stage 0 intake + Stage 1 research into a one-page tight brief that constrains all downstream design work.

## What the Tight Brief Contains
1. **Category + mode** (from Stage 0)
2. **Audience** — who, what they care about, what makes them leave
3. **Positioning** — one sentence: what this product/site IS
4. **Emotional arc** — the feeling journey from landing to conversion
5. **Three Dials** — locked values from Stage 0 (DESIGN_VARIANCE / MOTION_INTENSITY / VISUAL_DENSITY)
6. **Constraints** — brand colors/fonts (if set), accessibility requirements, industry-specific rules
7. **Competitive landscape** — top 3 competitors and what to learn/avoid from each
8. **Key trends** — 3-5 trends from the research that apply to this category
9. **Anti-references** — what NOT to look like (from competitor weaknesses or user input)

## Rules
- One page maximum — if it does not fit on one page, it is not tight enough
- Every statement must be traceable to Stage 0 inputs or Stage 1 evidence
- No assumptions — if something is unclear, escalate to the user before locking
- Dial values are LOCKED after this stage — changes require user approval

## Output
Tight Brief written to: `docs/ux-challenge/[YYYY-MM-DD]-[category-slug]-tight-brief.md`
